# ORG-X 能力一览

ORG-X 是一个研究雷达：帮助你发现哪些企业可能正在把 AI 用进核心生产系统，并把“值得继续研究什么、为什么、还缺什么资料”整理出来。

你可以先从下面的用户目标开始，再点击详情链接深入阅读。能力页说明的是研究用途和使用边界，不把未确认的资料写成事实，也不把研究优先级写成投资建议。

状态先这样理解：**已提供**表示可以按说明使用；**有边界**表示依赖明确的资料或环境；**需外部确认**表示还要回到原始资料或真实服务核对；**不提供**表示不属于 ORG-X 的用途。

## 你会看到的研究标签

- **Top5**：当前最多五个最值得优先阅读的研究对象。
- **Rising**：支持其结构性变化的证据正在增强。
- **Watch**：已有研究价值，但还需要更多证据或后续观察。
- **Dropped**：原有结构性证据减弱、失效，或不再满足当前比较条件。

这些标签是研究排序，不是公司好坏排名，更不是投资建议。具体排序和阶段判断，仍应回到证据和资料来源。

## 使用前要知道

1. 外部资料先作为线索和候选事实，优先核对一手来源；发现型资料不能直接变成权威结论。
2. 资料有歧义、来源冲突或关键字段缺失时，结果会保留“未知”或“不可用”。
3. 单一新闻、单个 AI 工具、裁员或合作公告，不足以证明企业核心生产方式已经重写。
4. 研究规则、示例资料或报告格式，不能替代对真实数据、生产环境或持续业务结果的确认。

## 明确不提供什么

- 不提供买入、持有、卖出、价格预测、仓位或其他交易/资本行动建议。
- 不让模型在缺少来源时凭经验补出事实，也不把未经溯源的自动抽取当成最终证据。
- 不把单一消息自动升级为生产方式变化，不把研究排序包装成经济结果。
- 不把研究资料或示例结果当成企业已经接入真实业务、已经运行或已经产生长期结果的证明。

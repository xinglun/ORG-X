# Transformation Stage Model

## Six stages

| Stage | Meaning | Upgrade boundary |
| --- | --- | --- |
| `TOOL` | AI 是工具 | 不构成转型证据。 |
| `SUBSTITUTION` | AI 替代局部人工任务 | 旧组织和旧 Workflow 仍然主导。 |
| `WORKFLOW` | Workflow 围绕 AI 重构 | AI 执行、人监督；核心生产系统尚未根本变化。 |
| `PRODUCTION_SYSTEM` | 核心价值创造过程围绕 AI 重设计 | 需要 Workflow、Decision、Responsibility、Organization 多类证据。 |
| `PRODUCTIVITY_BREAKOUT` | 新生产方式产生持续经济优势 | 需要 Stage 3、持续生产率差异和经济捕获。 |
| `REFERENCE_MODEL` | 新生产方式向行业扩散 | 需要持续优势、竞争者模仿和行业扩散。 |

## 转换规则

Stage 不能因为一篇新闻跳跃。升级至少需要多个证据类别、独立来源和持续性；Stage 4 需要多个季度的 persistence 和 peer divergence；Stage 5 必须极其罕见，并有模仿和扩散证据。

每次转换保存 Transition Date、Trigger Evidence IDs、Supporting Categories、Counter Evidence、Confidence 和 Missing Proof。企业可以从 Stage 3 降回 Stage 2，这表示原判断被后续事实否证。

# ORG-X Phase 0 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可编译、可测试、可审计的 ORG-X Rust 基础工程，并在不实现业务功能的前提下固化 DDD/Clean Architecture、North Star、核心领域文档和架构守门。

**Architecture:** 采用单 Cargo crate 的模块化 Bounded Context。每个 Context 建立 `domain`、`application`、`infrastructure`、`interface`、`acl` 入口；当前只放边界说明和模块声明。标准库 Architecture Tests 扫描 `src`，防止领域层反向依赖外部实现。

**Tech Stack:** Rust stable toolchain, Cargo, Rust standard library, Make, Markdown。

## Global Constraints

- Evidence before Score.
- Production System before Organization.
- Stage before Ranking.
- Counter-evidence is mandatory.
- AI extracts; Rust decides.
- ORG-X 研究生产方式，不产生交易决策。
- Domain 不得依赖 `reqwest`、`sqlx`、LLM SDK、SEC implementation、news provider 或 renderer。
- 依赖方向固定为 `interface -> application -> domain`；外部实现只能通过未来 ports/adapters 接入。
- 本计划不实现 Universe、Evidence、Production System、Transformation、Ranking 或任何数据抓取业务。
- 每个任务在独立可验证后提交一次 Git commit。

- Test names are stable and correspond one-to-one with the five project-mandated rules.

- [ ] **Step 1: Write the source scanner helpers**

Use only `std::fs`, `std::path::{Path, PathBuf}`, and `env!`:

```rust
fn source_files_under(relative: &str) -> Vec<PathBuf> {
    fn collect(path: &Path, files: &mut Vec<PathBuf>) {
        let Ok(entries) = fs::read_dir(path) else { return };
        for entry in entries.flatten() {
            let child = entry.path();
            if child.is_dir() { collect(&child, files); }
            else if child.extension().is_some_and(|ext| ext == "rs") { files.push(child); }
        }
    }

    let mut files = Vec::new();
    collect(&Path::new(env!("CARGO_MANIFEST_DIR")).join(relative), &mut files);
    files.sort();
    files
}
```

The helper must read each file with `fs::read_to_string`, lowercase it, and panic with the path and forbidden token when a match exists. It must scan only `src`, never the tests themselves.

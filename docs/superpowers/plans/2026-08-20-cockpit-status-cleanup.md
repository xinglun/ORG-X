# Cockpit Stale Status Cleanup Plan

## Goal

Remove the tracked live Cockpit snapshot for the nonexistent `wi-06-status-interface`
Work Item so the repository cannot report a historical red blocker as current state.

## Boundaries

- Preserve `.ai/work-items/archive/index.json` and every archived Contract, Summary,
  Outcome, and archive manifest.
- Do not change Rust code, tests, dependencies, workflows, external services, or
  governance check implementations.
- The only implementation change is deletion of the orphan live status snapshot and
  its generated index; the canonical no-active state remains generated by lifecycle
  tooling.

## Execution

1. Capture the before state: the stale snapshot, its red index entry, the 35-item
   archive count, and clean branch/worktree facts.
2. Run the required `before_edit` checkpoint, then delete only the two declared live
   Cockpit snapshot files.
3. Regenerate and validate the no-active Cockpit status, run all required governance
   checks and `make quality`, and update the Summary with exact evidence.
4. Run `before_finish`, `make ai-finish`, archive the Work Item, run `make check-ai-pr`,
   create the hosted PR, wait for required checks, merge it, and run
   `make ai-close-work-item`.
5. Re-audit the archive count, branch/worktree state, live Cockpit state, and remote
   synchronization after closure.

## Acceptance Evidence

- No tracked live `.ai/cockpit/work-items` index or `wi-06-status-interface` status
  snapshot remains.
- The authoritative archive remains unchanged at 35 entries before this WI is added
  and 36 after its archive transaction.
- All required AI Cockpit checks and project quality checks pass.
- The PR is merged and the Work Item closure command verifies clean local and remote
  state.
